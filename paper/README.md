# Paper

Paper assets are organized by role:

- `manuscript/`: current TeX manuscript, appendix, references, class file, and tracked figure PDFs.
- `response/round-01/`: formal first-round journal response package.
- `snapshots/`: synchronized working PDFs that are not treated as confirmed journal submissions.
- `submission/`: frozen files only after confirmed journal submission.

Build outputs belong in ignored `build/` directories.
