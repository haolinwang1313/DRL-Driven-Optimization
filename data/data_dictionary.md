# Data Dictionary

## Canonical Morphology Descriptors

These columns appear in `data/generated/canonical_2000/simulated_samples.csv` and related result tables.

| Field | Meaning | Unit |
| --- | --- | --- |
| `sample_id` | Canonical sample identifier | integer |
| `FAR` | Floor area ratio | dimensionless |
| `SD` | Height variation | m |
| `AF` | Average floors or floors-related descriptor | floors |
| `AR_ew` | East-west canyon aspect ratio | dimensionless |
| `AR_ns` | North-south canyon aspect ratio | dimensionless |
| `SVF` | Sky-view openness proxy | dimensionless |
| `BD` | Building density | dimensionless |
| `OSR` | Open-space ratio | dimensionless |
| `SC` | Envelope exposure descriptor | dimensionless |
| `PAR` | Perimeter-area ratio | m^-1 |
| `theta` | Block orientation angle | degrees |
| `OSLI` | Open-space location index | integer 0-8 |
| `weather_station` | Reference weather station label used by the analytic dataset | text |
| `simulation_mode` | Target-generation mode | `fallback_analytic` |

## Targets

| Field | Meaning | Unit |
| --- | --- | --- |
| `EUIt` | Energy Use Intensity target | kWh m^-2 y^-1 |
| `EG` | Energy Generation analytic target | 10^6 kWh y^-1 |
| `H` | Winter sunlight-hours target | h |

`simulated_samples.csv` is generated by `fallback_analytic` response construction. It is not a direct annual EnergyPlus/Radiance simulation dataset. Physical stress-test outputs are separate selected-case summaries in `results/physical_stress/`.

## Optimizer and Result Columns

| Field | Meaning |
| --- | --- |
| `method` | Optimizer family or result source |
| `scenario` | Scalarization or evaluation scenario |
| `seed` | Random seed index where applicable |
| `reward` | Optimizer objective value used by the released run table |
| `episode` | Training episode index in DDPG training summaries |
| `reward_mean` | Mean cumulative episode reward across seeds |
| `reward_std` | Standard deviation of cumulative episode reward across seeds |
| `HV` | Hypervolume metric in the released benchmark summary |
| `IGD` | Inverted generational distance metric in the released benchmark summary |
| `projection_distance` | Distance to the nearest feasible generated block |
| `matched_sample_id` | Canonical sample identifier after feasible projection |
| `subset` | Physical stress-test subset label |
| `station` | Climate sensitivity station label |
| `delta_EUIt_vs_baseline` | EUIt change relative to the Dongtai baseline weather case |
| `delta_EG_vs_baseline` | EG proxy change relative to the Dongtai baseline weather case |
| `delta_H_vs_baseline` | H change relative to the Dongtai baseline weather case |
| `physical_EUIt` | Selected-case physical stress-test EUIt output |
| `physical_EG_GHI_proxy` | Selected-case physical stress-test EG proxy output |
| `physical_H` | Selected-case physical stress-test sunlight-hours proxy |

The public catalog records exact paths, row counts, SHA-256 hashes, and release roles for every committed data/result file.
