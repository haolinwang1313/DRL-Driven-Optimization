# Research Integrity Spec

Repository maintenance must not change scientific meaning.

Do not modify numerical algorithms, random seeds, model hyperparameters, optimization budgets, imported result artifacts, manuscript scientific claims, or substantive reviewer-response content during structure-only work.

Do not invent missing evidence. If empirical validation, physical-stack closure, server outputs, benchmark data, or journal-submission proof is absent, record it as absent or unverified.

Do not treat internal automated-review rounds as formal journal rounds. Use formal journal-round labels only when supported by submission or decision evidence.

Do not commit secrets, local server configs, `.env` files, API keys, SSH keys, virtual environments, generated artifacts, or agent runtime state.
