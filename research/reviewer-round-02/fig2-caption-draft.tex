Figure 2. Serialized static black-box search used in the DDPG
benchmark. (a) At each query step, the actor maps the normalized
three-target state to an absolute 12-dimensional normalized morphology-
descriptor action. Gaussian exploration noise is added before the action
is clipped and mapped to the sampled descriptor bounds. The guarded DNN
surrogate then returns the next normalized target state and the
normalized-distance reward, and the resulting transition is stored for
actor--critic updating. (b) Each episode begins from a random descriptor
query and terminates after 40 sequential surrogate interactions. Each
scenario is trained independently for 600 episodes across 20 seeds. The
sequence represents repeated policy-training queries rather than
physical time evolution or incremental modification of one urban block.
